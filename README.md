# FIFA Game page

An Arabic (right-to-left) landing page for a FIFA game: hero section, features, screenshots gallery and a download section. The download button is disabled on purpose because there is no game file. Built with HTML, CSS and JavaScript, and the AOS library for scroll animations.

Live: https://islam-osama2024.github.io/FIFA.com/

Files: `index.html`, `main.css`, `js.js`, `img/`.
